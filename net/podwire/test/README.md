# test — 종단 검증 스크립트

단위 테스트는 각 패키지 옆에 두고(`*_test.go`), 여기에는 **클러스터를 실제로 띄워야
확인되는 것**만 스크립트로 둔다. Stage 마다 하나씩 늘어난다.

| Stage | 확인할 것 |
|---|---|
| 1 | 3노드에서 CoreDNS 포함 전 Pod `Running`, 다른 노드 Pod 끼리 ping |
| 2 | kube-proxy 없이 ClusterIP 응답, 백엔드 분산 비율 |
| 3 | default-deny 후 허용 규칙만으로 통신, 카운터로 어느 규칙이 잡았는지 |
| 4 | `PW-*` 체인이 빈 상태에서 ClusterIP 응답 |
| 5 | 암호화 on/off 로 `tcpdump` 결과가 갈린다 |
| 6 | 노드 사이 캡처에 TLS 만 보인다 |
| 6b | 가중치 90:10 이 100회 요청에서 비율로 나온다 |
