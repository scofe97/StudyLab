# 0002. 재접속은 지수 백오프에 지터를 섞는다

- 상태: 채택
- 날짜: 2026-10-20
- 장: ch03

## 맥락

agent 는 provd 와의 연결이 끊기면 다시 붙어야 합니다. 재시도 간격을 고정하면 provd 가 재시작될 때 여러 agent 가 같은 순간에 몰려 provd 를 다시 쓰러뜨릴 수 있습니다. 처음 값, 배수, 상한, 지터를 정해야 합니다.

## 선택지

### A. 고정 간격 (1초)

- 장점: 단순하고 복구가 빠릅니다.
- 단점: provd 장애 때 재접속이 한꺼번에 몰립니다.

### B. 지수 백오프 + 지터

- 장점: 몰림을 막고, 장기 장애 중에도 provd 부하가 낮습니다.
- 단점: 상한 근처에서는 복구가 최대 30초 늦어집니다.

### C. 지수 백오프만 (지터 없음)

- 장점: B 보다 단순합니다.
- 단점: 같은 시각에 끊긴 agent 들이 계속 같은 시각에 재시도합니다.

## 결정

B 를 고릅니다. 처음 값 1초, 배수 2, 상한 30초, 지터 ±20% 로 시작합니다. 한 provd 에 여러 장비 agent 가 붙는 구조라 재접속 몰림 방지가 핵심이고, 지터는 한 줄이면 더할 수 있기 때문입니다. 연결이 성공하면 간격을 처음 값으로 되돌립니다. 수치는 상수로 두어 바꿀 수 있게 합니다.

## 결과

- 쉬워지는 것: provd 재시작 직후의 재접속 몰림이 줄어듭니다.
- 어려워지는 것: 장기 장애 뒤 복구가 최대 30초(지터 포함 약 36초) 늦어질 수 있습니다.
- 다시 볼 조건: 리허설에서 복구가 너무 늦거나 몰림이 보이면 수치를 다시 정합니다.
