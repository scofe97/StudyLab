# 등록이 몰리는 시간대에 조회까지 느려진다 (J1)

- 장: ch09
- 날짜: 2026-10-29~30 (재검사 2026-11-01)
- 앞 장면과의 연결: 8장이 끝난 프록시(ADR 0012)는 프록시↔서버 구간에만 기한이 있었다. 손님↔프록시 구간은 헤더 읽기 5초 말고는 기한이 없었다.

## 신고

> "장비 등록이 몰리는 시간대에 단건 조회까지 몇 초씩 걸립니다."

### 창이 몰래 켠 장애

등록 요청 일부가 몸통을 2초에 1바이트씩 보낸다(`npgload -body-every 2s`, 초당 2건). 느린 업로드 공격(slow POST, Slowloris 계열)과 같은 모양이다.

## 진단 과정

| 순서 | 본 신호 | 세운 가설 | 남김 / 버림과 이유 |
|---|---|---|---|
| 1 | 조회 대부분 5초 안팎, 접근 로그 flags `-` | 프록시→백엔드가 막혔다 (학습자) | 버림. 백엔드 대기열은 비어 있었다 |
| 2 | GET 을 뺀 로그에 `POST 504 UT dur=30000 bytes=0` | 업스트림 기한 15초가 지나도 몸통을 기다리는 고루틴을 못 깨운다. 몸통 읽기 기한이 없다 (학습자) | 남김. 느린 POST 가 프록시의 백엔드 연결 칸을 30초씩 붙잡아 조회가 칸을 기다렸다 |
| 3 | 핫픽스로 `ReadTimeout` 10초를 넣음 | 이제 끊긴다, flags 는 UT (학습자 예측) | 끊긴다는 맞음. flags 는 틀림: 85건 모두 `499 DC`(손님 이탈) |
| 4 | net/http 는 읽기 기한이 지나도 연결 context 를 그냥 취소한다 | DC 로는 진짜 이탈과 기한 초과를 구분 못 한다 (학습자) | 남김. 몸통을 감싼 마디가 첫 오류(EOF 냐 timeout 이냐)를 적어 두면 구분된다 |

## 실행 전 예측

재검사 예측은 ADR 0014 「결과」에 적었다: 느린 POST 는 10초 안팎에 `408 CT` 로 끊긴다.

## 실행

창이 같은 스크립트로 고치기 전 바이너리와 고친 뒤 바이너리를 각각 돌렸다. 조회 초당 50(50초) + 느린 POST 초당 2(40초).

## 전후 수치

| 지표 | 처음(기한 없음) | 핫픽스(`ReadTimeout` 10초) | 고친 뒤(ADR 0014) |
|---|---|---|---|
| 느린 POST 결과 | 손님 30초 기한으로 포기 83/83 | `499 DC` 90/90, 10.0초 | `408 CT` 75/75, 10.0초 |
| 조회 p99 | 7.6초 | 3.5초 | 12ms |
| 기록이 말하는 원인 | 업스트림 기한(UT) | 손님이 떠남(DC) — 틀린 말 | 손님이 느림(CT) |

## 포스트모템

- 근본 원인: 손님 몸통 읽기에 기한이 없어, 느리게 흘리는 손님이 프록시의 백엔드 연결 칸을 오래 붙잡았다. 핫픽스는 끊기는 했지만 원인을 "손님 이탈"로 잘못 남겼다.
- 제품은 이렇게 막는다: nginx `client_body_timeout`(읽기 사이 간격, 408), caddy `read_idle_timeout` + `read_min_rate`. 기록은 nginx 408/499, haproxy `cR`/`CR` 처럼 "느림"과 "떠남"을 나눈다.
- 조치(ADR 0014 결정 1): 몸통 읽기 틈 10초 + 최소 속도 초당 1KB(10초 뒤부터 잼). 걸리면 `408` 과 새 flag `CT`. 전체 시계 `ReadTimeout` 은 뺐다(큰 업로드를 자르지 않으려고).
- 재발 방지: `internal/proxy/downstream_test.go` 가 흘리는 손님·멈춘 손님·떠난 손님·몸통 뒤 느린 업스트림을 각각 시험한다. 고의 결함 넷(EOF 기한 지우기 빼기 등)을 넣어 모두 시험이 잡는 것을 확인했다.

## 원문 근거

- Go 1.25.1 `net/http/server.go` `connReader` 의 읽기 오류 처리(`handleReadErrorLocked` → `cancelCtx`).
- 제품 기본값·표기: ADR 0014 「원문 근거」 (nginx 1.31.8, envoy v1.40.2, haproxy 3.4.0, caddy v2.11.7).
