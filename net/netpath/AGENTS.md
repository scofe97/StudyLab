# AGENTS.md

짧게, 행동 규칙만. 설계 근거와 배경은 `docs/` 에 둔다.

## 개발 원칙

- 개념·중복·의식(ceremony)을 줄인다.
- 안정된 계약 하나에 실제 주인 하나.
- 성급한 추상화보다 지역적 단순함을 택한다.
- 간접 계층은 실제 결합을 없애거나 실제 경계를 지킬 때만 추가한다.
- 테스트는 안정된 계약과 불변식을 지키는 것이지, 명세를 대신하거나 회귀 방지만을 위해 존재하지 않는다.

## 이 프로젝트의 규칙

- **`probe/` 는 Kubernetes·OpenTelemetry·서비스 메시를 모른다.** 이 경계가 무너지면 관측 계층을 갈아끼울 수 없다. `make lint` 가 강제한다.
- **`types/` 가 유일한 계약이다.** 모든 exporter 는 `types.Result` 만 읽는다. 계약을 런타임 패키지에 두면 의존 방향이 뒤집힌다.
- **오류는 값으로 분류한다.** `errors.Is`/`errors.As` 만 쓰고 메시지 문자열은 절대 매칭하지 않는다. 메시지는 어느 패키지의 계약도 아니다.
- **실행되지 않은 단계는 0ms 가 아니다.** `StatusSkipped` 로 구분한다.
- **프로브마다 새 Transport.** 커넥션 재사용은 `ConnectStart`·`TLSHandshakeStart` 훅을 통째로 건너뛴다.
- **프로버는 재시도하지 않는다.** 재시도는 관측 대상이지 프로버의 기능이 아니다.
- 상태 없는 공용 변환은 `utils/`, 도메인 로직은 그 주인 곁에.

## 검증

- `make check` (vet + lint + test) 를 커밋 전에 돌린다.
- `make lint` 는 gofmt 와 `probe/` 코어 경계를 함께 본다.
